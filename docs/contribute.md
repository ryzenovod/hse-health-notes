# Как добавить следующий конспект

Создайте Markdown-файл в папке нужного предмета. Затем добавьте его в навигацию `mkdocs.yml`.

## Минимальный шаблон

```markdown
---
title: Короткое название лекции
description: Одно предложение о содержании
---

# Название предмета: тема лекции

| | |
| :--- | :--- |
| **Лектор** | Имя Фамилия |
| **Дата** | ДД.ММ.ГГГГ |

!!! abstract "Коротко"
    - Один тезис на одну мысль. Число пунктов зависит от лекции.

## Основной конспект

### Название раздела

Сохраняйте определения, формулы и примеры из лекции.

## Термины

### Для не-медиков

- **Термин** — простое объяснение.

### Для не-экономистов и не-статистиков

- **Термин** — простое объяснение.

## Задания и сроки

- Домашняя работа:
- Срок сдачи:
- Формула оценки:
```

## Редакционные правила

- Убирайте слова-паразиты, паузы и повторы, но сохраняйте ход аргументации лектора.
- Отделяйте слова лектора от редакторских пояснений.
- Не превращайте корреляции в причинные утверждения.
- Помечайте даты и правила, которые нужно перепроверить в LMS.
- Объясняйте медицинские термины для менеджеров и экономические — для врачей.

!!! warning "Персональные данные"
    Не публикуйте данные пациентов, закрытые ссылки на занятия, номера телефонов, личную переписку и материалы с ограниченным доступом.
