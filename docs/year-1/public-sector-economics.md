# Экономика общественного сектора

Курс про то, зачем в экономике нужен общественный сектор, где рынок не справляется сам и почему государственные решения тоже не становятся автоматически хорошими.

## Оценивание

| Часть | Вес |
| :--- | :---: |
| Экзамен | 50% |
| Активность на семинарах | 25% |
| Эссе | 25% |

Итоговая оценка: **50% экзамен + 25% активность на семинарах + 25% эссе**.
