## Государство, рынок и эффективность { #sector }

| Термин | Значение |
| :--- | :--- |
| **Общественный сектор** | Часть экономики, в которой решения о ресурсах принимаются коллективно, а финансирование и распределение благ в значительной степени идут через общественные институты. В материалах курса используется широкая трактовка: государство и некоммерческие организации. |
| **Смешанная экономика** | Сочетает рыночную координацию, государственное регулирование и разные формы собственности. |
| **Провал рынка** | Рыночный механизм не обеспечивает эффективного по Парето распределения ресурсов. Типичные причины: рыночная власть, внешние эффекты, асимметрия информации и трудности предоставления общественных благ. |
| **Провал государства** | Потери из-за того, как государство принимает и исполняет решения. Их могут вызывать неполная информация, влияние групп интересов и слабый контроль над исполнителями. |
| **Парето-улучшение** | Изменение, при котором хотя бы один человек выигрывает, а положение остальных не ухудшается. |
| **Парето-эффективность** | Состояние, в котором больше нельзя получить Парето-улучшение. |
| **Критерий Калдора — Хикса** | Изменение считается улучшением, если выигравшие способны полностью компенсировать чужие потери и сохранить часть выигрыша. Критерий оценивает возможность компенсации; фактическое распределение доходов зависит от того, состоится ли выплата. |
| **Позитивный анализ** | Объясняет, как устроена экономика и к каким последствиям приводит решение. Например, как налог меняет цену и объём продаж. |
| **Нормативный анализ** | Оценивает, какое решение желательно, исходя из выбранных критериев эффективности и справедливости. |

Парето-эффективность совместима с сильным неравенством. Поэтому при выборе политики оценивают и общий результат, и распределение выигрышей и потерь между людьми.

## Общественные блага

| Термин | Значение |
| :--- | :--- |
| **Несоперничество, или неконкурентность** | Использование блага одним человеком сохраняет доступный остальным объём. При этом каждый может оценивать пользу от него по-своему. |
| **Неисключаемость** | Исключить неплательщика из потребления невозможно либо слишком дорого. |
| **Чистое общественное благо** | Одновременно неисключаемое и несоперничающее благо. Типичный пример — национальная оборона. |
| **Частное благо** | Доступ к нему можно ограничить, а потреблённая единица достаётся одному пользователю. Эти свойства сохраняются при частной и при государственной оплате. |
| **Смешанное благо** | Свойства неисключаемости и несоперничества проявляются не полностью либо зависят от условий использования. |
| **Клубное благо** | Исключаемое благо с совместным потреблением. До перегрузки дополнительный участник почти не мешает остальным; при перегрузке качество снижается. |
| **Перегружаемое благо** | Сохраняет несоперничество лишь до определённого числа пользователей. Например, дополнительная машина почти не мешает движению на свободной дороге, а в пробке увеличивает задержки. |
| **Общий ресурс** | Соперничающее благо, доступ к которому трудно ограничить. Например, рыбные запасы в открытом водоёме. |
| **Проблема безбилетника** | Человек рассчитывает пользоваться совместно оплачиваемым благом, не внося свою долю. Если так поступают многие, денег на благо не хватает. |
| **Селективные стимулы** | Выгоды или санкции, зависящие от личного участия в коллективном действии. Они помогают сделать вклад выгодным для отдельного участника. |
| **Условие Самуэльсона** | Суммарная готовность пользователей платить за дополнительную единицу общественного блага равна затратам на её производство: `ΣMBᵢ = MC`. Условие относится к внутреннему эффективному решению при отсутствии дополнительных искажений финансирования. |
| **Цены Линдаля** | Индивидуальные цены, или доли оплаты, одного общественного блага. При равновесии все согласны с общим объёмом, хотя платят за единицу по-разному. |

Медицинская помощь сочетает разные свойства. Время индивидуального приёма ограничено, поэтому здесь есть соперничество за ресурс. Государственная оплата такого приёма обеспечивает доступность помощи и распределяет финансовые риски между участниками системы.

## Внешние эффекты и информация { #information }

| Термин | Значение |
| :--- | :--- |
| **Внешний эффект, или экстерналия** | Выгода или ущерб третьим лицам от производства или потребления, которые участники сделки не учитывают полностью в своём решении. |
| **Положительный внешний эффект** | Дополнительная выгода для третьих лиц. При прочих равных рынок производит благо в меньшем объёме, чем общественно эффективно. |
| **Отрицательный внешний эффект** | Дополнительный ущерб третьим лицам. При прочих равных рыночный объём превышает общественно эффективный. |
| **Интернализация** | Включение внешних выгод или издержек в расчёт того, кто принимает решение: через налог, субсидию, договор или другой механизм. |
| **Налог Пигу** | В базовой модели налог на единицу деятельности, равный предельному внешнему ущербу при эффективном объёме. Он сближает частные и общественные издержки. |
| **Теорема Коуза** | При чётких правах собственности и нулевых трансакционных издержках стороны могут договориться об эффективном использовании ресурсов. Первоначальное распределение прав определяет, кому достанется доход и кто заплатит компенсацию. |
| **Трансакционные издержки** | Затраты на поиск информации и партнёров, переговоры, заключение договора, контроль и защиту прав. |
| **Естественная монополия** | Одна фирма может обеспечить соответствующий объём рыночного спроса с меньшими совокупными издержками, чем несколько фирм. |
| **Асимметрия информации** | Одна сторона сделки располагает значимой информацией, недоступной другой. |
| **Неблагоприятный отбор** | Скрытые характеристики участников меняют состав заключаемых сделок. В страховании люди с более высоким риском охотнее покупают полис по общей для всех цене. |
| **Моральный риск** | Договор меняет стимулы участника, чьи действия трудно контролировать. Например, страховое покрытие может снижать осторожность или увеличивать потребление медицинских услуг, поскольку часть расходов оплачивает страховщик. |

Различие между неблагоприятным отбором и моральным риском разобрано также в [учебнике OpenStax](https://openstax.org/books/principles-economics-2e/pages/16-2-insurance-and-imperfect-information).

## Благосостояние и перераспределение { #redistribution }

| Термин | Значение |
| :--- | :--- |
| **Перераспределение** | Изменение распределения доходов или ресурсов с помощью налогов, трансфертов и других мер. Его направление зависит от того, кто финансирует программу и кто получает выгоды. |
| **Утилитаризм** | Подход, при котором максимизируют сумму индивидуальных полезностей. Предпочтительное распределение доходов зависит от того, как доход влияет на полезность каждого участника. |
| **Эгалитаризм** | Подход, придающий самостоятельную ценность равенству: доходов, возможностей или доступа к благам — в зависимости от выбранной концепции. |
| **Роулсианская функция благосостояния** | Учебная модель `W = min(U₁, …, Uₙ)`: результат оценивают по положению наименее благополучного участника. |
| **Либертаризм** | Связывает справедливость прежде всего с соблюдением прав собственности и добровольностью приобретения и передачи благ. |
| **Кривая Лоренца** | Показывает, какая накопленная доля дохода приходится на соответствующую долю населения, упорядоченного от бедных к богатым. |
| **Коэффициент Джини** | Мера неравенства на основе кривой Лоренца. Для неотрицательных доходов лежит между `0` и `1`: чем больше значение, тем выше неравенство. Иногда выражается в процентах. |
| **Социальный трансферт** | Передача денег или благ без встречного предоставления текущего товара или услуги. Примеры — пособие и помощь в натуральной форме. |
| **Ловушка бедности** | Рост заработка почти не увеличивает располагаемый доход либо снижает его из-за налогов и потери пособий. |
| **Социальная помощь** | Поддержка, право на которую обычно определяется нуждаемостью или принадлежностью к установленной категории. |
| **Социальное страхование** | Коллективное покрытие установленных социальных рисков через страховую систему. Условия участия, взносов и выплат задаются её правилами. |

## Общественный выбор

| Термин | Значение |
| :--- | :--- |
| **Теория общественного выбора** | Применяет экономический анализ к политическим решениям: изучает стимулы избирателей, политиков, чиновников и групп интересов. |
| **Методологический индивидуализм** | Объяснение коллективных результатов через действия и взаимодействие отдельных людей. |
| **Рациональный выбор** | Человек последовательно выбирает наиболее предпочтительный из доступных вариантов с учётом своих ограничений и информации. Предпочтения могут включать доход, досуг, помощь другим и любые другие значимые для него результаты. |
| **Полнота предпочтений** | Человек может сравнить любые две альтернативы: предпочесть одну либо считать их равноценными. |
| **Транзитивность предпочтений** | Если `A` не хуже `B`, а `B` не хуже `C`, то `A` не хуже `C`. |
| **Рациональное неведение** | Человек ограничивает сбор политической информации, когда затраты на её изучение превышают ожидаемую личную выгоду. Участие в голосовании при этом зависит от его собственных издержек и мотивов. |
| **Парадокс Кондорсе** | Попарное голосование большинства может образовать цикл: группа предпочитает `A` варианту `B`, `B` варианту `C`, но `C` варианту `A`. |
| **Медианный избиратель** | Участник в середине упорядоченного ряда предпочтений. При одномерном выборе и одновершинных предпочтениях его наиболее желательная альтернатива не проигрывает большинству другой альтернативе. |
| **Теорема Эрроу** | При трёх и более альтернативах невозможно для любых полных транзитивных индивидуальных предпочтений получить полный транзитивный общественный порядок и одновременно соблюсти принцип Парето, независимость от посторонних альтернатив и отсутствие диктатора. |
| **Логроллинг** | Обмен поддержкой по разным вопросам голосования. |
| **Лоббирование** | Организованное влияние на решения власти в интересах определённой группы. |
| **Поиск ренты** | Расходование ресурсов ради привилегий, позволяющих присваивать часть уже созданного дохода: например, ради исключительного доступа к рынку. |
| **Группа специальных интересов** | Участники с общим экономическим интересом, которые объединяются, чтобы влиять на решения. |
| **Бюрократия** | Организация с иерархией должностей, разделением полномочий и формальными правилами. |
| **Модель Нисканена** | Бюро стремится увеличить бюджет и использует преимущество в информации об издержках. В базовой модели это может привести к выпуску выше общественного оптимума. |

Примеры голосования и график модели Нисканена — в конспекте [«Общественный выбор и бюрократия»](public-sector-economics-public-choice.md).

## Налоги

| Термин | Значение |
| :--- | :--- |
| **Налог** | Обязательный платёж, который не является ценой конкретной услуги, предоставляемой плательщику в обмен. |
| **Налоговая система** | Совокупность налогов и правил их установления, расчёта, взимания и контроля. |
| **Прямой налог** | Непосредственно связан с доходом или имуществом плательщика. |
| **Косвенный налог** | Налог на товары, услуги или операции с ними. Его экономическое бремя распределяется через изменение цен и доходов. |
| **Средняя ставка** | Доля налога в налоговой базе: `T(Y) / Y`. |
| **Предельная ставка** | Доля дополнительной единицы базы, которую забирает налог: `ΔT / ΔY`, а для гладкой функции — `dT/dY`. |
| **Пропорциональное налогообложение** | Средняя ставка постоянна при росте дохода. |
| **Прогрессивное налогообложение** | Средняя ставка растёт с доходом. Это возможно и при одной предельной ставке с необлагаемым минимумом. |
| **Регрессивное налогообложение** | Средняя ставка снижается при росте дохода. |
| **Маркированный, или целевой, налог** | Поступления связаны с определённым направлением расходов. Маркировка налога — установление этой связи. |
| **Принцип платёжеспособности** | Обязательства распределяют с учётом экономических возможностей плательщиков. |
| **Принцип получаемых выгод** | Вклад в финансирование соотносят с выгодами, получаемыми от соответствующих общественных расходов. |
| **Горизонтальное равенство** | Люди с одинаковыми значимыми для налогообложения характеристиками несут одинаковые обязательства. |
| **Вертикальное равенство** | Люди с разными экономическими возможностями несут различающиеся обязательства в соответствии с выбранным принципом справедливости. |
| **Гибкость налоговой системы** | Способность поступлений и правил приспосабливаться к изменениям экономической ситуации. |
| **Экономическое налоговое бремя** | Потери реальных доходов и благосостояния после введения налога. Через цены и доходы они распределяются между участниками рынка, включая тех, кто перечисляет налог в бюджет. |
| **Перемещение налога** | Перенос части бремени на других участников через цены, заработную плату, доходность капитала и другие условия сделок. |
| **Искажающий налог** | Меняет относительную привлекательность вариантов выбора и вызывает эффект замещения: например, делает досуг выгоднее по сравнению с дополнительным часом работы. |
| **Паушальный налог** | Фиксированный платёж, величина которого задана независимо от текущих решений плательщика. В стандартной модели он сокращает доступный доход, сохраняя относительные цены вариантов выбора. |
| **Избыточное налоговое бремя** | Потеря благосостояния сверх суммы, перешедшей в бюджет. В простой модели товарного налога без исходных искажений связана с сокращением взаимовыгодных сделок. |

## Расходы и бюджетный федерализм { #federalism }

| Термин | Значение |
| :--- | :--- |
| **Общественное финансирование** | Государство или другой общественный институт оплачивает предоставление блага. Производителем может быть частная организация. |
| **Общественное производство** | Благо производит организация общественного сектора. Источник оплаты и выбор производителя определяются отдельно. |
| **Квазирынок** | Поставщики конкурируют за заказ или выбор пользователя, а финансирование и правила доступа организует государство. |
| **Анализ «затраты — выгоды» (CBA)** | Затраты и результаты проекта оценивают в денежных единицах с учётом времени их возникновения. |
| **Анализ «затраты — эффективность» (CEA)** | Сравнивают затраты на результат в общих натуральных единицах, например на дополнительный год жизни. |
| **Анализ «затраты — полезность» (CUA)** | В здравоохранении сопоставляет затраты с результатом, учитывающим продолжительность и качество жизни, обычно с QALY. |
| **Бюджетный федерализм** | Распределение расходных полномочий, доходов и трансфертов между уровнями власти. Такие отношения существуют и в унитарных государствах. |
| **Вертикальное выравнивание** | Согласование доходных возможностей и расходных полномочий разных уровней власти. |
| **Горизонтальное выравнивание** | Сокращение различий в бюджетных возможностях территорий одного уровня. |
| **Гипотеза Тибу** | В модели мобильные и информированные граждане выбирают территорию по сочетанию местных налогов и общественных услуг — «голосуют ногами». |
| **Эффект липучки** | Трансферт местному бюджету может увеличивать местные общественные расходы сильнее, чем сопоставимый рост частных доходов жителей. |
