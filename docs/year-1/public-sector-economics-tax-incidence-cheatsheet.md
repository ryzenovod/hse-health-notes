# Налоги — формулы и условия { #tax-cheatsheet }

<span id="1"></span>

## Средняя и предельная ставка { #tax-rates }

$$ATR=\frac{T}{Y},\qquad MTR=\frac{\Delta T}{\Delta Y}.$$

| Изменение $ATR$ при росте дохода | Тип шкалы |
| :--- | :--- |
| Растёт | Прогрессивная |
| Постоянна | Пропорциональная |
| Снижается | Регрессивная |

Для гладкой функции налога $d(ATR)/dY=(MTR-ATR)/Y$. В таблице $MTR$ относится к интервалу между двумя соседними доходами.

<span id="2"></span>

## Равновесие и доход бюджета { #equilibrium-revenue }

До специфического налога: $Q_D(P_0)=Q_S(P_0)=Q_0$.

После налога за единицу:

$$Q_D(P_D)=Q_S(P_S)=Q_t,\qquad P_D-P_S=t,\qquad T=tQ_t.$$

Обозначение $T$ относится к налогу; $TR=P_SQ_t$ — чистая выручка продавца в этой модели. При адвалорном налоге на чистую базу $P_D=(1+\tau_n)P_S$; на полную базу $P_S=(1-\tau_g)P_D$.

<span id="3"></span>

## Распределение бремени { #incidence }

В конкурентной модели при одинаковом налоговом правиле юридический плательщик сохраняет то же равновесие. Ценовое бремя за единицу:

$$B_D=P_D-P_0,\qquad B_S=P_0-P_S,\qquad B_D+B_S=t.$$

Для сохранившихся сделок: $B_DQ_t+B_SQ_t=T$. Потери излишков дополнительно учитывают исчезнувшие сделки.

<span id="4"></span>

## Эластичности и доли { #elasticities }

$$\varepsilon=\frac{dQ}{dP}\frac{P}{Q}.$$

Большая доля приходится на менее эластичную сторону. Для небольшого налога в конкурентном частичном равновесии, с эластичностями в общей исходной точке:

<span id="_2"></span>

$$\text{Доля покупателя}=
\frac{\varepsilon_S}{\varepsilon_S+|\varepsilon_D|}.$$

<span id="_3"></span>

$$\text{Доля продавца}=
\frac{|\varepsilon_D|}{\varepsilon_S+|\varepsilon_D|}.$$

Для линейных обратных кривых $P_D=a-bQ$, $P_S=c+dQ$ точные доли равны $b/(b+d)$ и $d/(b+d)$, пока торговля сохраняется.

| Форма кривой | Кто несёт весь клин | Количество | $DWL$ |
| :--- | :--- | :--- | :--- |
| Вертикальный спрос | Покупатель | $Q_t=Q_0$ | 0 |
| Горизонтальный спрос | Продавец | $Q_t<Q_0$ | Положителен |
| Вертикальное предложение | Продавец | $Q_t=Q_0$ | 0 |
| Горизонтальное предложение | Покупатель | $Q_t<Q_0$ | Положителен |

В таблице другая кривая обычная наклонная, исходный обмен эффективен и после налога сохраняется положительная торговля.

<span id="5"></span>

## Излишки и чистые потери { #dwl }

$CS$ — площадь под спросом и над ценой покупателя; $PS$ — площадь над предложением и под чистой ценой продавца, до $Q_t$.

Для линейных кривых, специфического налога и эффективного исходного рынка:

$$DWL=\frac12t(Q_0-Q_t),\qquad
\Delta CS+\Delta PS=T+DWL.$$

При неизменном количестве $DWL=0$. Внешний ущерб и монополия меняют общественную оценку: корректирующий налог может уменьшить исходные потери.

Аккордный платёж $T=F$ создаёт эффект дохода при прежних относительных ценах. В базовой модели его избыточное бремя равно нулю.

<span id="6"></span>

## Порядок расчёта { #calculation }

1. Найти исходную цену и количество из равенства спроса и предложения.
2. Записать полную цену покупателя и чистую цену продавца, связав их налоговым правилом.
3. Решить новое равновесие и подставить обе цены в соответствующие функции.
4. Найти $T$, изменения цен, излишков и количества.
5. Проверить $P_D-P_S=t$ и, для линейной модели, $\Delta CS+\Delta PS=T+DWL$.

На рынке труда работодатель — покупатель, работник — продавец. При налоге с брутто-зарплаты $w_S=(1-\tau)w_D$, доход бюджета $T=\tau w_DL_t$.

<span id="7"></span>

## Обозначения { #notation }

| Символ | Значение |
| :--- | :--- |
| $P_0,Q_0$ | Цена и количество до налога |
| $P_D,P_S,Q_t$ | Цена покупателя, чистая цена продавца и количество после налога |
| $t$ | Денежный налог на единицу |
| $\tau$ | Доля указанной налоговой базы |
| $T$ | Сумма налога, налоговые поступления |
| $TR$ | Выручка фирмы |
| $CS,PS$ | Излишки потребителя и производителя |
| $DWL$ | Чистая потеря выигрыша от обмена |
